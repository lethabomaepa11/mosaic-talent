# Developer how-to guide

Issue [#127](https://github.com/lethabomaepa11/mosaic-talent/issues/127) adds `/app/how-to`, a short, developer-facing guide for the first complete Mosaic Talent journey.

The guide explains how to complete a profile, discover a project, create a project, collaborate in the workspace, document contributions, and use peer feedback. Each step links directly to the relevant part of the application. The route is available from desktop navigation and from the mobile More drawer. Mobile navigation keeps Discover, Reviews, and Profile visible, with Projects, How to use, and Settings in the More drawer. The mobile header contains search and notifications only; appearance is available from Settings.

The page uses a phone-first single-column layout, then expands naturally on larger screens.
