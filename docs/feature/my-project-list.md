# My Projects list

My Projects presents one project per row and keeps the New Project action in the page header. Developers can switch between active and completed projects, search titles, descriptions, and skills, filter by one or more skills or difficulty, and sort by title, creation date, or weekly hours.

The list uses the existing `GetMyProjects` response and project cards, so no backend or database changes are required. The filters adapt to phone, tablet, and desktop widths.
