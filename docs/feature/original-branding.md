# Original mosaic.talent branding

The canonical display name is **mosaic.talent**, as explicitly clarified by the owner. Restore the original gold circle-and-lightning emblem and wordmark after the practical UI redesign had substituted a four-tile mark and the spaced name “Mosaic Talent”. The clean project/task layouts remain.

## Assets and display names

- `frontend/public/logo.svg`: original emblem for collapsed navigation, favicon, and install metadata.
- `frontend/public/text-logo-light.svg`: original wordmark with dark lettering for light surfaces.
- `frontend/public/text-logo.svg`: original wordmark with white lettering for dark surfaces.

These SVG files are reused unchanged. The shared `Brand` component selects the full wordmark by the saved appearance preference and the original emblem when navigation is collapsed. It is used in the landing header, desktop sidebar, mobile app header, and signup header. Existing login and company navigation also retain their original logo assets.

Visible product labels, accessible names, page title, PWA name/short name, installation notices, and push-notification fallback names use `mosaic.talent`. Native wrapper display-name source settings follow the same spelling; existing APK binaries are not regenerated by this web preview update. Repository paths, backend namespaces, API routes, cookie keys, application IDs, and configured domains retain their technical identifiers.

The signup heading is the direct action “Create account”, consistent with the owner's saved preference for plain labels and minimal slogans.

The existing notification center exceeded the repository's source-file limit. Its list rendering and presentation helpers were separated into `NotificationList.tsx` and `helpers.tsx` while updating the installation message. Notification actions and delivery behavior remain in the existing provider; no API or permission flow was added.
