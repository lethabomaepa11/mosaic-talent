# AI project match comparison

AI Match Me is available on both the signed-in developer's Discover page (the post-login destination) and My Projects. It presents the AI-selected best fit alongside the next two projects ranked by the existing skills-and-goals match score. Each card shows fit, relevant skills, expected weekly hours, team capacity, and a link to inspect project details. The AI pick includes its explanation and learning outcomes when available.

Developers can start joining from the comparison. The existing workload check runs first and requires an explicit confirmation when it flags an overload. The comparison adapts to three columns on desktop, two on tablet, and one on narrow phones.

The feature uses existing project matching endpoints and data. No schema change or migration is required.
